# AGENTS.md

Static export (HTML dump) of the Portuguese government portal gov.pt.
Next.js static export, `lang="pt-PT"`. No build step: pages are committed
HTML that must be edited in place.

## Hard rules

- Do NOT edit or add CSS files in `assets/_next/static/css/*`. The `ap-*`
  overlay ships its own inline `<style id="ap-styles">` inside `<head>`.
- Do NOT change the existing layout or markup of the portal.
- No emojis anywhere. Use inline SVG icons.
- Only modify `index.html`, `registro.html`, and `assets/` when needed.

## Editing generated HTML safely

`index.html` and `registro.html` contain huge single-line React hydration
payloads. To keep diffs reviewable, injected blocks are delimited by markers
and are re-generated by an idempotent injector:

- `<head>`: `<!-- ap-overlay:start --> ... <!-- ap-overlay:end -->`
  contains `<style id="ap-styles">`, `<div id="ap-root">`, `<div id="ap-alert">`.
- before `</body>`: `<script id="ap-boot">` with the whole overlay logic.
- `<script id="nav-links-keep-page">` restores the original "primary nav
  links do not navigate" behaviour.

Regenerating both pages must be idempotent: strip the previous blocks, then
re-inject before `</head>` and `</body>`. Always re-validate
`<script id="__NEXT_DATA__">` as JSON after editing.

## Acesso Privado overlay

Standalone fixed overlay (`#ap-root`, `#ap-alert`, CSS prefix `ap-`). It does
not touch existing CSS/classes, and reuses the portal tokens
(`--color-primary-500:#1a65fa`, `--color-success-600:#00724c`,
`--color-neutral-200:#e1e4ea`, `--radius-4/8/16`, `--z-dialog`).

Flow when the user activates "Acesso Privado" in the header:
1. 5s loading loop with a spinner and the official partnership message.
2. Process selection: Residência or Carteira de Condução.
3. Full name of the holder.
4. ~4.4s simulated processing log, then an affirmative result (process
   started, with reference) or a no-match result.

Auto-check: the result is affirmative only when the typed name and the chosen
process both match `REGISTRY` in `ap.js`.

### Administering the registry

Edit the `REGISTRY` array (or use the runtime API on `window.AcessoPrivado`):

```js
AcessoPrivado.add("Ana Silva", "residencia"); // add a process
AcessoPrivado.check("Ana Silva", "residencia"); // true/false
AcessoPrivado.registry; // the live list
AcessoPrivado.open(); // open the area
```

Names are compared accent/case-insensitively. If `REGISTRY` is emptied the
`FALLBACK` list is used so the demo keeps working.

### Global link blocking

While installed, every `<a href>` outside the overlay gets
`preventDefault()` and shows a short, context-aware "Acesso Privado" alert
(search, primary nav, header, footer, content). The search bar and the
magnifier stay fully functional: the alert is dismissed on outside click
(`#ap-alert` has `pointer-events:none`, only the card is clickable). The
"Autenticar" header link opens the overlay instead of showing the alert.
